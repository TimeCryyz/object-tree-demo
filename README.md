# ObjectTreeDemo

Лабораторная работа №2. Дерево объектов QObject в Qt.

## Цель

Изучить понятие дерева объектов QObject, научиться создавать виджеты
с явным родителем, продемонстрировать автоматическое удаление дочерних
объектов при удалении родителя, исследовать setParent().

## Что демонстрирует

- Создание виджетов с родителями (LogLabel, LogLineEdit, LogPanel, LogButton).
- Отслеживание создания/уничтожения через qDebug() в конструкторах и деструкторах.
- Автоматическое удаление детей при удалении родителя.
- Смену владельца через setParent() с обновлением layout.
- setParent(nullptr) — отвязка виджета и ручное удаление через deleteLater().
- Безопасные указатели QPointer для проверки, жив ли объект.

## Сборка

1. Открыть ObjectTreeDemo.pro в Qt Creator.
2. Собрать.
3. Запустить.

## Что показывает консоль

- [CREATE] ... — при создании каждого виджета.
- [DESTROY] ... — при уничтожении.
- [SET_PARENT] ... — при смене родителя.
- [DEMO] ... — количество детей до/после setParent(nullptr).

## Управление

- «Переместить виджет» — переключает m_movable между панелью и главным окном.
- «Удалить панель» — удаляет панель через deleteLater(). Если m_movable внутри — удалится автоматически.
- «Демо setParent(nullptr)» — создаёт временную панель, отвязывает одного ребёнка и удаляет обоих.

## Технологии

- Qt 6.11.2, MinGW 13.1.0, qmake.
- QWidget, QVBoxLayout, QLabel, QLineEdit, QPushButton, QFrame.
- QPointer для безопасных указателей.
